# Support

This is a community, pre-1.0 project with no guaranteed response time or commercial SLA.

* Usage/configuration: GitHub Discussions when enabled, otherwise a documentation issue.
* Reproducible defects: bug issue form with Gauge, runner, OS, plugin version, flags, and sanitized diagnostics.
* Compatibility gaps: compatibility issue form and `allure-report doctor` output.
* Security: private process in [SECURITY.md](SECURITY.md).
* Conduct: private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Search existing issues and [troubleshooting](docs/troubleshooting.md) first. Minimal Gauge projects are preferred to screenshots. Maintainers may close requests outside the roadmap, dependent on unsupported upstreams, or lacking reproducible information.
